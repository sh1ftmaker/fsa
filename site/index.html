Four Swords Adventures

A byte-matching decompilation: C and C++ that the original Metrowerks compilers turn back into the exact bytes of the game. This page tracks every function of the DOL.

The whole DOL

Area is bytes of code. The bright fill rising in each tile is matched code; the paler band above it is structural progress (size × match % of structurally matched functions). Labels give structural progress first, matched code second. The game code is coloured by its eight categories (or, switched, by boot-path phase), the libraries in gold. Tap or click to dive in: region, category or library, file, function.

Libraries

Nintendo's and Metrowerks' code the game links: the Dolphin SDK, GX, JSystem, and MSL, Runtime and MetroTRK. Imported from other decompilations and finished file by file. Pick one to open it in the map.

Game code

FSA's own code in eight categories, by what each file is. Solid bars are matched code; the lighter extension is structural progress (size × match % of structurally matched functions).
